# 定价与商业模型校准 — Stealth Writer AI

## 1. 竞品锚点

| 竞品 | 免费额度 | 付费起步 | 月付价格 | 特点 |
|------|---------|---------|---------|------|
| stealthwriter.ai | 有限试用（约 300 words） | $10/月 | $20-50/月 | 功能全，但免费少 |
| undetectable.ai | 有限试用 | $9.99/月 | $29.99/月 | 检测+改写一体 |
| hidemy.ai | 未知 | 未知 | 未知 | 新兴，信息少 |

**价格锚点：**
- 市场接受月付 $10-30
- 免费额度是转化关键（用户先体验再付费）
- 无注册体验是差异化（竞品多需注册）

## 2. 成本模型

### DeepSeek API 成本（假设使用 DeepSeek-V3）
- 输入：$0.14 / 1M tokens
- 输出：$0.28 / 1M tokens
- 平均请求：1,000 tokens 输入 + 1,500 tokens 输出
- 单次成本：~$0.00049（约 $0.0005）

### Cloudflare Workers
- 免费额度：100,000 requests/day
- 超出：$0.30 / million requests
- 当前成本：≈ 0（在免费额度内）

### 免费用户成本上限
| 日活用户 | 人均请求 | 日请求 | API 成本/日 | API 成本/月 |
|---------|---------|--------|------------|------------|
| 100 | 3 | 300 | $0.15 | $4.50 |
| 500 | 3 | 1,500 | $0.75 | $22.50 |
| 1,000 | 3 | 3,000 | $1.50 | $45.00 |
| 5,000 | 3 | 15,000 | $7.50 | $225.00 |

**免费用户成本天花板：$225/月（5,000 DAU）**

### 付费用户边际成本
- 付费用户单次成本：$0.0005
- 月付 $10 用户需使用 > 20,000 次才亏（不可能）
- 利润空间：> 95%

## 3. 套餐设计

### Free（免费）
- 每日额度：3,000 words（约 3-5 次请求）
- 无注册，无历史，无 API
- 标准改写模式
- 广告支持（可选）

### Pro（付费）
- 月付：$9.99
- 年付：$79.99（省 33%）
- 无限字数（公平使用：50,000 words/月）
- 优先速度（< 2 秒）
- 多种改写模式（正式 / casual / 学术 / 创意）
- 检测评分（AI 检测概率）
- 无广告

### Lifetime（终身）
- 一次性：$199
- 等同于 Pro 永久
- 限量 100 份（ scarcity 营销）
- 30 天退款保证

### 为什么不设 Business 档？
- 首版聚焦个人用户
- API 售卖、团队协作属 P2（后续迭代）
- 不伪装成可购买套餐

| 支持 | 社区 | 邮件 | 邮件 |

**明确限制：**
- 无"无限"承诺
- 公平使用政策：超过 50,000 words/月需联系升级
- 禁止自动化/批量处理（反滥用）

## 5. 转化口径

### 定价页结构
1. **价值先行**："Make AI text undetectable in seconds"
2. **适用人群**：学生、撰稿人、营销人员
3. **套餐对比**：Free vs Pro vs Lifetime
4. **社交证明**："Trusted by 10,000+ writers"
5. **CTA**："Start Free → Upgrade When Ready"

### 免费 → 付费触发场景
- 用完每日 3,000 words
- 需要多种改写模式
- 需要检测评分
- 速度变慢（免费队列）
